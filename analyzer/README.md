# Replay Analyzer Tools

Этот каталог содержит готовые инструменты для автоматического и пошагового анализа реплеев змейки.

## Доступные инструменты:

1. **`run_analysis.py`** — Утилита для глубокого сравнительного анализа и расчёта геометрических метрик.
2. **`visualize_steps.py`** — Пошаговый консольный визуализатор с поддержкой вывода ASCII-карт и датчиков.

---

## 1. Сравнительный и одиночный анализ (`run_analysis.py`)

Этот скрипт рассчитывает метрики связности пространства, плотности скручивания, выявления зацикливаний и Manhattan-расстояния до еды.

### Примеры использования:

* **Сравнительный анализ всех сохранённых игр**:
  Сравнит метрики победных и проигравших игр из `.runtime/replays/` и выведет сводную таблицу:
  ```bash
  python analyzer/run_analysis.py
  ```

* **Анализ конкретного файла реплея**:
  Выведет подробную статистику по конкретной игре:
  ```bash
  python analyzer/run_analysis.py .runtime/replays/replay_score_95_ep_2183_live_1782705357.json
  ```

---

## 2. Пошаговая визуализация (`visualize_steps.py`)

Этот скрипт отображает состояние игрового поля в ASCII формате на выбранном шаге, включая положение головы, тела, хвоста, еды, а также список активных сенсоров нейросети на этом шаге.

*Автоматически определяет кодировку вашей консоли (например, CP1251 на Windows) и безопасно заменяет эмодзи на текстовые ASCII маркеры в случае её несовместимости.*

### Примеры использования:

* **Показать финальный шаг (момент смерти)** последней игры:
  ```bash
  python analyzer/visualize_steps.py
  ```

* **Показать последние 5 шагов** последней игры:
  ```bash
  python analyzer/visualize_steps.py --last 5
  ```

* **Показать конкретный шаг 150** конкретной игры:
  ```bash
  python analyzer/visualize_steps.py .runtime/replays/replay_score_95_ep_2183_live_1782705357.json --step 150
  ```
