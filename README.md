# Snake Neural Lab

Проект представляет собой систему обучения нейронных сетей (Reinforcement Learning) для игры "Змейка". Система включает в себя симуляцию среды, агентов на базе DQN (Deep Q-Network) и эволюционных алгоритмов (Evolutionary Algorithms), гибридную архитектуру нейросети и веб-интерфейс для визуализации процесса обучения.

## Структура проекта

### Основные файлы логики (Python)

*   **`backend_config.py`**: Централизованный файл конфигурации. Содержит все константы: размеры полей, параметры нейросети, коэффициенты наград/штрафов и метки сигналов.
*   **`snake_env.py`**: Ядро игрового движка. Реализует класс `SnakeEnv`, который управляет состоянием игры, обрабатывает ходы, вычисляет награды и штрафы, а также генерирует входные данные (наблюдения) для нейросети.
*   **`web_backend.py`**: Серверная часть (API), которая связывает логику обучения с веб-интерфейсом. Позволяет транслировать состояние игры и статистику обучения в браузер.
*   **`web_api.py`**: HTTP-сервер для взаимодействия фронтенда с бэкендом, обеспечивающий обработку API-запросов (состояние, кадры, команды).
*   **`networks.py`**: Описание архитектуры нейронной сети. Использует `HybridBoardEncoder` для одновременной обработки пространственных данных (карты поля через сверточные слои) и глобальных признаков (через полносвязные слои).
*   **`dqn_agent.py`**: Реализация алгоритма обучения с подкреплением. Содержит класс `DQNAgent`, который управляет процессом выбора действий, обучением сети через `ReplayBuffer` и оптимизацией весов.
*   **`evolution_agent.py`**: Реализация эволюционного алгоритма для обучения популяции агентов. Использует механизмы селекции, кроссовера (скрещивания) и мутации геномов нейросети для поиска оптимальных стратегий без использования градиентного спуска.
*   **`smart_agent.py`**: Специализированный агент на базе TensorFlow/Keras. Использует более сложную систему признаков (lookahead, floodfill) и работает через отдельный процесс-воркер для обеспечения стабильности при работе с тяжелыми моделями `.h5`.

### Веб-интерфейс и вспомогательные файлы

*   **`index.html`**: Основная страница веб-приложения.
*   **`snake_lab_app.js`**: Клиентская логика на JavaScript, отвечающая за отрисовку игры и взаимодействие с сервером.
*   **`styles.css`**: Стили оформления интерфейса.
*   **`app_config.js`**: Конфигурационный файл для веб-интерфейса.
*   **`app_utils.js`**: Вспомогательные функции для работы веб-приложения.

### Служебные файлы и папки

*   **`.runtime/`**: Папка для хранения промежуточных данных: логов производительности, сохраненных моделей (`.h5`, `.pt`) и статистики обучения.
*   **`start_web.ps1`**: PowerShell скрипт для быстрого запуска веб-интерфейса.
*   **`start-aider-web-picker.ps1`**: PowerShell скрипт для удобного выбора модели в LM Studio и запуска aider в веб-режиме.

## Технологический стек

*   **Языки**: Python (логика и обучение), JavaScript (интерфейс).
*   **Библиотеки**: `PyTorch` (нейросети), `NumPy` (вычисления), `TensorFlow/Keras` (для специализированного агента).
*   **Методы обучения**: Deep Q-Learning (DQN) с использованием гибридных признаков, Эволюционный алгоритм.
