# Snake Neural Lab

Локальная лаборатория обучения с подкреплением (Reinforcement Learning) для игры «Змейка» с живой веб-визуализацией процесса обучения, графа нейросети и диагностикой качества на полях от `10×10` до `35×35`.

## Быстрый старт

### Требования
- Python 3.12 (`venv/` в корне проекта)
- Основные пакеты: `torch` (CPU), `numpy`, `numba`
- Опционально: `tensorflow` / `h5py` (только для инференса моделей `Zmey-smart` `.h5`)

### Запуск веб-интерфейса
```powershell
.\start_web.ps1
```
или напрямую:
```powershell
.\venv\Scripts\python.exe web_backend.py --host 127.0.0.1 --port 8000
```
После запуска откройте в браузере `http://127.0.0.1:8000`.

## Агенты и режимы

| Агент | Архитектура | Входы | Обучение |
|---|---|---|---|
| **PPO (Map)** | Actor-Critic (`Conv 24→32` + split MLP `128→64`, ~85.8k пар.) | `11×11` эго-карта (4 канала) + `40` сигналов | 16 параллельных сред, **Мульти-поле**, Failure-Replay, EMA, Anti-Drift |
| **DQN** | Dueling Double DQN (MLP `64→32`) | `34` относительных сигнала | Prioritized Experience Replay + N-step |
| **Zmey-smart** | Внешняя Keras-модель (`.h5` из `.runtime/`) | Внутренние признаки модели | Только режим «ИИ» (инференс) |

### Ключевые возможности PPO
- **Мульти-поле** (тумблер в шапке UI): фоновые 16 сред обучаются на мягко-взвешенном миксе с упором на текущую выбранную карту и якорем на `10×10` (например, на `10×10` — `8×10 + 4×15 + 4×20`, на `15×15` — `8×15 + 5×10 + 3×20`, на `20×20` — `7×20 + 6×10 + 3×15`). Это одновременно ускоряет рост на больших полях и повышает точность на базовой `10×10`.
- **Чистая 1-step политика**: без lookahead, перебора дерева и предрасчитанных гамильтоновых циклов — локальное окно `11×11` переносится на любые размеры карт.
- **Ускорение на CPU**: BFS-ядро скомпилировано через `numba` (`@njit(cache=True)`), свёртки работают в `channels_last` (`NHWC`), буферы rollout предвыделены.
- **Тест (20)**: честная greedy-оценка текущей сети прямо из UI без влияния на обучение и статистику.

## Структура проекта

### Ядро и агенты (Python)
- **`backend_config.py`** — единая конфигурация: размеры карт, метки сигналов (`34` для DQN, `40` для PPO), награды/штрафы, гиперпараметры сетей.
- **`snake_bfs_numba.py`** — скомпилированное Numba JIT-ядро BFS (34 сигнала + 3 `area_ratio` + эго-карта `11×11` за один проход).
- **`snake_env.py`** — игровая среда `SnakeEnv`: физика змейки, кэш наблюдений, сериализация состояния.
- **`networks.py`** — нейросети PyTorch (`DuelingQNetwork` для DQN, `PPOMapNetwork` для PPO).
- **`ppo_agent.py`** — `PPOAgent`, `ParallelPPORunner` (single и multi-board, Failure-Replay по картам, EMA, Anti-Drift, температурная эскалация выхода из голодных петель).
- **`dqn_agent.py`** — `DQNAgent`, `PrioritizedReplayBuffer` (SumTree) и общие хелперы оценки рисков.
- **`smart_agent.py`** — обёртка для инференса `.h5`-моделей `Zmey-smart`.

### Веб-бэкенд и телеметрия
- **`web_backend.py`** — состояние симуляции, фоновый воркер PPO, потокобезопасное переключение агентов/карт и автосохранение.
- **`web_api.py`** — HTTP-сервер, REST API (`/api/state`, `/api/frame`, `/api/command`, `/api/health`) и SSE-поток `/api/frame_stream`.
- **`telemetry.py`** — упаковка статистики решений, связей графа сети и правил наград под активного агента.
- **`runtime_storage.py`** — атомарное сохранение JSON-статистики и логирование производительности.

### Фронтенд (HTML / CSS / JS)
- **`index.html`**, **`styles.css`** — интерфейс приложения (игровое поле, HUD-панель управления, граф сети, графики, «Итог игры»).
- **`app_config.js`**, **`snake_lab_app.js`**, **`snake_renderers.js`** — клиентская логика, SSE-синхронизация и canvas-рендеринг.

### Тесты и стенды оценки (`tests/`)
- **`tests/test_snake_env.py`**, **`tests/test_agents.py`**, **`tests/test_web_backend.py`** — юнит-тесты среды, агентов, мульти-поля и HTTP/SSE API.
- **`tests/eval_ppo.py`**, **`tests/eval_dqn.py`** — консольные стенды честной оценки и классификации причин смертей на любых картах.

### Рабочие данные (`.runtime/`)
- `snake_ppo.pt`, `snake_dqn.pt` — чекпоинты весов и оптимизаторов.
- `*.h5` — модели `Zmey-smart`.
- `snake_model_stats.json` — история эпизодов, графики и рекорды по картам.
- `active_context.json` — последние настройки интерфейса.

## Проверка и оценка моделей

Запуск юнит-тестов:
```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

Консольная оценка PPO (например, 100 игр на `10×10` или 25 на `15×15`):
```powershell
.\venv\Scripts\python.exe tests\eval_ppo.py --board 10 --episodes 100
.\venv\Scripts\python.exe tests\eval_ppo.py --board 15 --episodes 25
```
