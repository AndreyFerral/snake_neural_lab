Snake + Reinforcement Learning

Змейка с обучением нейросети

Интерфейс работает в браузере, а сама нейросеть и цикл обучения выполняются в Python backend. Размер входа модели можно переключать отдельно от игрового поля, и для каждого входа хранится своя обученная модель.
